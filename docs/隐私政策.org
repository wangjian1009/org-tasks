* 我们如何处理您的信息

| 使用场景             | 处理的信息                                            | 用途和去向                                                                                                                                                             |
|----------------------+-------------------------------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 任务、项目和备忘     | 您填写的标题、正文、标签、日期、清单及选用的 Org 文件 | 用于在设备上保存、展示、编辑和查询记录。您可以使用应用专用目录或选择系统允许访问的其他目录。                                                                           |
| 文件分享、备份和恢复 | 您主动选取或分享的文件、链接及配置                    | 用于导入配置、创建记录或将配置保存到您选择的位置。配置备份可能包含 WebDAV 地址和用户名。Org 正文保存在文件仓库中，WebDAV 密码保存在设备安全存储中。                    |
| 可选的 WebDAV 同步   | 服务器地址、用户名、密码和待同步的 Org 文件           | 测试连接或同步时，设备通过 HTTPS 直接连接您配置的服务器。地址和用户名保存在设备配置中，密码通过鸿蒙 Asset Store 保存。远端文件的保存和处理取决于您选择的 WebDAV 服务。 |
| 语音录入和标题识别   | 主动录入的音频、转写结果和输入的任务标题              | 录音用于生成任务标题。应用优先调用鸿蒙离线语音识别。离线识别引擎无法使用时，华为在线识别服务处理录入的音频。应用可调用鸿蒙自然语言处理能力从标题识别日期和地点。       |
| 任务提醒和通知       | 任务标题、提醒日期、时间和任务标识                    | 启用日历提醒后，应用在本机专用日历中创建、更新或删除对应事件，由系统日历发出提醒。系统通知权限用于显示提醒和角标。                                                     |
| 地图分享和外部链接   | 您主动分享或打开的链接，以及链接关联的地址或经纬度    | 分享高德地图短链接时，应用可能向高德请求解析。您可以把位置保存到任务中。打开链接时，所选地图、浏览器或其他应用接收相应链接或查询内容。                                 |
| 应用关联             | 目标应用的包名、安装状态、图标和您保存的关联          | 用于在设备上显示可打开的目标应用，以及按您设置的关联打开链接。                                                                                                         |

设备权限按照功能场景使用。语音录入使用麦克风，任务提醒使用日历和通知，文件操作使用系统授予的文件访问权限。后台运行能力用于您启用的同步功能。您可以通过鸿蒙系统设置管理权限及通知，也可以在应用设置中关闭相应功能。

* 保存与删除

本地任务、备忘、配置和同步记录按其所在目录及功能保存，直至您清理或删除相关内容。
任务移入废纸篓后，可在清理前恢复，也可手动永久清除。废纸篓默认保留 30 天，您可以在设置中调整期限。

移除存储库会清除应用中的仓库配置和保存的 WebDAV 密码。
若要删除本机 Org 文件或远端副本，请分别在对应目录或您选择的 WebDAV 服务中处理。
您主动导出的备份也由您管理。

停止 WebDAV 同步可在对应仓库设置中选择「不同步」。
您可以结束语音录入，也可以在鸿蒙系统设置中撤回麦克风权限。
日历提醒可在应用的「任务提醒」设置中关闭。
通过第三方完成的处理，适用该服务提供方的保存和删除规则。

* 您的权利与联系我们

您可以在应用中查阅、更正和删除任务及备忘，也可以在设置中导出应用配置。
如需提出个人信息查阅、复制、更正、删除、撤回同意或投诉请求，请通过本政策所列邮箱联系开发者。
我们会在适用法律规定的期限内答复，并按请求所需核验身份。

* 政策更新

如处理目的、方式、信息类型或第三方服务发生变化，我们会更新隐私政策并通过应用向您展示。
依法需要重新取得同意的，我们会在开展相关处理前取得您的同意。
