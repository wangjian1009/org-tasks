#+TITLE: 文件内 TRIGGER 触发器
#+LANGUAGE: zh-CN
#+OPTIONS: author:nil date:nil toc:nil

* 依据与执行时机

以本机 Emacs 的 Org 9.8.10 与 org-edna 1.1.2 为参考，移植文件内可执行的 TRIGGER 规则。Core 原生解释字符串，不调用 Emacs、不执行 Lisp，也不读取或修改联动目标之外的文件。本文明确区分已支持规则和静默跳过范围，不声称支持整个 Emacs 运行时。

状态从文件有效待办集合进入有效完成集合时，先完成 Org 自身的状态日志和重复调度，再读取来源条目的 ~TRIGGER~ 。因此重复任务中的 ~self scheduled!("+2d")~ 以已经推进的日期为基准； ~todo!(NEXT)~ 可以覆盖自动恢复的待办状态。完成状态之间切换、待办之间切换、无状态标题进入完成以及新建完成记录，不触发 TRIGGER。

默认对应 ~org-edna-use-inheritance=nil~ 、 ~org-edna-from-todo-states=todo~ 、 ~org-edna-timestamp-format=short~ 。TRIGGER 与普通动作属性只读取条目自身，不继承祖先、文件级 ~#+PROPERTY~ 或 SETUP 中的默认值；条目自身的追加属性仍有效。允许值列表如 ~CHOICE_ALL~ 按 Org 规则从祖先或文件配置取得。应用不提供 Emacs 全局自定义变量配置入口。

* 日期规则

~+Nunit~ 和 ~-Nunit~ 相对目标已有日期， ~++Nunit~ 和 ~--Nunit~ 相对当前时间。目标没有日期时，单符号相对操作失败；双符号操作可以创建日期。支持年、月、日、小时、分钟，月份与年份采用 Org 的日期溢出归一化。

落点支持指定星期、weekday／wkdy 和 weekend／wknd，可向前或向后调整；小时和分钟不应用落点。float 按源码中的实际顺序读取次数、星期、可选月份和可选日，月份为零或省略时使用相邻月份。

已有时间戳决定短／长格式；没有时间戳时，小时和分钟优先使用长格式，其余读取目标的 ~EDNA_TS_FORMAT~ ，最后采用 short。目标已有短格式时，即使动作单位为小时或分钟，也遵循 Edna 的短格式输出。复制使用来源的日期和时刻，不复制其重复器；普通设置保留目标原有重复器和预警。绝对日期时刻沿用 Edna 当前将空时区转换为 UTC 再输出本地时间的行为；相对时刻使用本地时间。

* 事务、定位与错误

全部联动只修改执行器持有的本文件隔离快照，沿用原状态操作的文件版本校验、一次提交、回退历史、同步上传意图和数据通知。宿主只提交原来的 TODO 字段，不组装联动操作，也不再次解析 TRIGGER。

触发器不增加、删除或移动标题。文件内用标题遍历位置保持身份，允许前方目标插入属性、修改状态或更新进度造成来源字节偏移变化；同组后续字段继续写入原来源节点。受保护冲突节点不能成为写入目标。

未支持动作静默跳过；已支持动作的非法参数、非法状态、日期溢出、无效语法及执行失败，均回滚整组，已完成的联动也不落盘。参数和条件嵌套限制为 64 层，联动链限制为 32 层，单次状态操作最多执行 4096 个规则或目标动作；循环联动报错回滚。顶层兄弟节点环绕使用有界遍历，不复制参考插件可能出现的无限循环。

* 验证与交付边界

参考结果通过运行本机 Emacs 的真实 Org Edna 获得，固定本地时间并隔离用户钩子和 ID 查找，记录 Org／Edna 版本与 UTC 偏移。比较任务状态、日期、属性和动作效果；规划字段的排列、属性 drawer 内的属性顺序及属性对齐不作为语义差异。Core 仍遵守原文保真约束，未涉及的字节由仓库级回归核对。

仓库级验证覆盖重复调度后执行、窗口与原日志保留、本文件目标限制、静默跳过后继续、前方目标导致来源偏移、级联、错误回滚和旧版本拒绝。手机继续复用原有完成入口和数据通知；本次未新增界面，也未进行真机验收。

Emacs 参考端拒绝 agenda 和外部文件访问，ID 只在当前样例查找。缺失 ID 返回空目标、本地 match 默认范围及顶层环绕的有界行为是本应用的明确约定，由仓库回归验证，不把参考插件的空 marker 或无限循环行为当作正确输出。
