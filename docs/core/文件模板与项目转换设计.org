#+TITLE: 文件模板与项目转换设计
#+STARTUP: show2levels
#+LANGUAGE: zh-CN

* 范围与接口

本次需求扩展既有任务操作组，新增与 ~Creation~ 平级的 ~FileNew~ 。模板渲染、文件创建、初始化记录的位置、版本校验与同步意图均由 Core 负责；Harmony 只读取随包模板、收集位置与名称并提交结构化操作。

~FileNew(TaskFileNew)~ 的目标为 ~path: TaskPath~ 文件根路径，包含真实仓库 ID 和安全相对 ~.org~ 文件名。其余字段为 ~template_path: String~ 、 ~template_content: String~ 、 ~arguments: Map<String, String>~ 与 ~init_tasks: Vec<TaskFileInitialTask>~ 。JSON 沿用 camelCase，即 ~templatePath~ 、 ~templateContent~ 与 ~initTasks~ 。

~TaskFileInitialTask~ 接受 ~title~ 、 ~body~ 、 ~state~ 、 ~priority~ 、 ~tags~ 、 ~scheduled~ 与 ~deadline~ ，不接受来源路径或插入位置；它通过既有 ~Creation~ 执行初始化。模板正文非空时优先采用内联正文，否则读取目标仓库中的 ~template_path~ ；两者都为空时可创建空文档。

* 模板渲染

模板占位符采用 ~{{name}}~ ，扫描模板取得字段名，并在 ~arguments~ 中逐项读取；字段缺失、空字段名或未闭合占位符返回输入错误。允许重复字段和未使用的额外参数；参数值中的占位符保持字面值，不做递归解释。

存在有效文件头 ~#+SETUPFILE:~ 时，按仓库中 ~.setup.org~ 的实际存在性处理：存在时补全引用路径，缺失时保留空的 ~#+SETUPFILE:~ 声明，再扫描其他模板参数。SETUPFILE 不作为模板参数，调用方不传入 ~setup_file~ 。源码块中的同名字面内容不作为文件头处理。保留模板原换行风格。新文件位于子目录时填写返回仓库根目录的相对 ~SETUPFILE~ 路径；配置读取只允许在仓库内归一化，不读取仓库外的设置。

模板顶部包含 ~:PROPERTIES:~ 、空的 ~:ID:~ 和 ~:END:~ 属性抽屉。Core 只扫描模板中真实属性抽屉的空 ~ID~ ，每个空值独立生成随机 UUID v4，采用与 org-roam 的 ~org-id-new~ UUID 模式一致的格式；已有 ID、CUSTOM_ID、源码块和参数值中的字面内容保留。生成仅发生于文件创建准备阶段，后续读取和移动不重新生成，失败不写盘。

* 初始化记录位置

- 生成文档没有根标题时，初始化记录位于第一层。
- 第一个根标题没有任务状态时，初始化记录位于其下，作为子标题。
- 第一个根标题有任务状态时，初始化记录位于其子树之后，作为同级标题。
- 多条初始化记录保持传入顺序。

~init_tasks~ 只创建新任务，不迁移既有记录。收件箱转换在一个操作组内组合 ~FileNew~ 与 ~Movement~ ，后者迁移完整原文子树，保留正文、创建时间、状态、标签、日志与子记录。随包项目模板没有根标题，源记录作为新文件的第一层标题移入；源记录的移出与新文件创建共同提交。

目标文件已存在时拒绝覆盖；模板缺参、源版本变化、初始化失败或普通提交失败，不得留下半个转换结果。模板和 ~SETUPFILE~ 作为读取依赖在提交前再次校验，变化时整组失败。成功后沿用既有文件与任务变更通知和同步基线比较，不引入独立的项目写入通道。

* Harmony 项目入口

项目模板 ~templates/project.org~ 和任务文件模板 ~templates/tasks.org~ 随 HAP 打包。Harmony 通过 ResourceManager 读取 UTF-8 原文，以 ~FileNew.templateContent~ 传给 Core。标题、分类与项目名称独立传入。项目名称为空时采用任务文件模板，保留 ~todo~ 标签。笔记本新增文件固定使用菜单所属仓库，通过单个 ~FileNew~ 创建文件。收件箱转换隐藏标题输入，默认使用项目名称作为标题，项目名称留空时使用源记录标题。两种表单的文件名均可单独指定，留空时按标题生成 ~.org~ 文件。

共享左滑按钮条增加独立的 ~enableConvertToProject~ ，默认关闭；只在收件箱主列表启用“项目”按钮，并保持“多选”为最后一项。点按后先保存当前草稿，再显示“转换为项目”表单。其他视图与最近新增不增加转换入口。创建失败保留表单和输入，成功后通过既有数据订阅刷新收件箱与侧边栏项目列表。
