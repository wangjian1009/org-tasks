* 目标与范围

在 Core Model 中统一定义任务创建、字段修改、移动和删除，提供批量操作组、完整路径、明文任务身份与回退历史。命令行调用同一 Core 入口；黑盒驱动按测试目的组织目录用例，逐字节比较最终文件。全部用例由一份 Org 文档集中描述。

本轮实现 Rust Core、命令行、测试驱动与设计文档，完成后迁移现有程序并删除旧增删改接口，不保留兼容入口；手机界面不新增入口。历史先保存在 workspace 内存，提供后续 undo、redo 所需的原始文件快照，本轮不提供撤销与重做入口。

* 执行语义

- 同组操作按列表顺序执行；后续操作使用前一步完成后的路径。改名和移动后须使用新路径。
- TaskPosition.after 为空时插入为 parent 下的首个子节点；不为空时插入在同级 after 的完整子树之后。
- taskId 仅对有效 TODO 配置识别的待办、已完成任务返回明文身份；无状态标题返回空值。fullPath 覆盖仓库、文件和所有标题节点，保留无状态祖先。
- 内存执行失败不写磁盘、不发布历史、不生成 outbox。提交阶段预备临时文件并校验磁盘版本，普通 I/O 失败回滚已提交文件；外部并发写入与进程崩溃的恢复边界须明确说明，不宣称普通文件系统具有跨文件原子替换能力。
- 回退快照只在全部提交成功后登记；保存修改前后的完整 UTF-8 原文，区分原先不存在的文件。

- 旧接口：Core、FFI、N-API 和 ArkTS 中的任务创建、直接更新、地址更新、直接删除及旧整理入口均已删除；同步文件合并与底层保真编辑端口保留各自职责。
