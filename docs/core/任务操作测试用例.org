* 范围与约定

每个用例是独立黑盒场景，按测试目的分组。对应目录为 ~core/tests/task_operations_cases/<组>/<用例>/~ ，输入、操作、预期输出分别保存在 ~input/~ 、 ~operations/~ 、 ~output/~ 子目录； ~case.json~ 记录目的、错误与附加断言。本文列出全部用例的实际定义，具体程序使用方式由程序帮助发现。

操作中的仓库名称是用例占位身份，执行前绑定到该输入仓库的稳定 Core ID。成功时检查操作历史与回退快照、最终文件清单及每个字节；失败时比较初始化后的全部文件和控制目录，要求文件、outbox 与临时文件均无变化。文件清单中包含空文件，不以删除空文件代替删除节点。

说明中的换行展示为 LF；涉及 CRLF 的文件会另行标注，磁盘样例才是逐字节比较依据。行尾空格以 ␠ 展示；源码块内逗号是 Org 引用转义，均不属于输入文件。
