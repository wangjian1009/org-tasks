* 本次范围

所有 TaskEditor 创建入口已经统一显式注入 DataManager 和一个绑定 DataSet。展示直接读取 DataSet，不再另收 task 参数；TaskEditor 不创建数据来源，也不再保留旧的全局数据监听、主动回查、按数据来源选择保存流程或按 operationId 解释确认事件的代码。

TaskEditor 收集标题、备注以及内嵌日期、标签、重复、优先级、链接、正文区块、清单的修改回调，统一提交字段数组。内嵌控件不获取 DataManager 或注册底层监控。具体接口、数据流和阶段语义见 [[file:页面数据集设计.org][页面数据集设计]]。

今天页的数据源为页面 DataSetManager，提供本地修改、后台队列、确认归并与磁盘缓存。项目详情从当前文件创建完整内存 DataSet，不使用页面缓存。其余页面的组合层将现有查询能力接入记录管理对象；接口迁移完成不表示所有页面已经迁移成页面级持久化数据集。

* 验收边界

上述页面验证使用专用模拟器 OrgPageDataQA 和隔离仓库，日期为 2026-11-15。用户编辑通过真实控件完成，再通过 APP 内嵌 HTTP 查询核对持久化结果；外部新增使用同一 Workspace 的修改 API。测试初始化材料与个人仓库隔离。

跨页面接口验收覆盖展开、输入、保存、确认事件和未修改字段保留；日志簿按其只读策略验证重新打开操作。今天页额外验证本地立即更新、关联数据、失败恢复与长列表位置保持。没有将普通数据源的编辑成功等同于该页已经具备页面级缓存。

* 查询接口清理的附加影响

通用 TaskQuery 已去掉组合任务包含开关，统一保留所有匹配条件的标题。现有业务请求此前均包含组合任务，页面筛选语义保持一致。除上述 TaskEditor 调用点外，共享查询组装还覆盖备忘、分享地点候选、桌面备忘与数字角标；Rust、Harmony 类型声明、APP REST 示例和对应检查已同步移除该字段。

当前前端回归检查为 523 项通过。项目文件数据集另覆盖文件一次读取、所有节点与 taskId 索引、改名后排队字段映射、外部关联变化、失败回滚及同名重建绑定隔离。调试包和数据准备包构建均无编译告警。
