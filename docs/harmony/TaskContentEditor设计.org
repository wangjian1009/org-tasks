* 当前实现与设计范围

~TaskContentEditor~ 用于任务卡片、日志簿只读展开和项目文档。正文覆盖任务、章节和文档导言的直属内容。任务标题、规划、属性、日志和后代任务由各自的控件负责。Core 按 ~orgize~ 无损语法树和 Emacs org-element 语义投影节点，Harmony 组合 ArkUI 控件。

* 控件树

#+begin_example
TaskContentEditor
├─ Paragraph                       行内文字、链接
├─ ListBlock                       普通、编号和 checkbox 条目共用
│  ├─ ListItem [ ]
│  │  ├─ Paragraph                 核对发布清单 [发布规范 ↗]
│  │  ├─ Paragraph                 补充说明 [测试报告 ↗]
│  │  ├─ TableBlock
│  │  │  └─ TableRow
│  │  │     ├─ TableCell           回归
│  │  │     └─ TableCell           [发布规范 ↗]
│  │  └─ ListBlock
│  │     └─ ListItem [ ]
│  │        └─ Paragraph           确认回滚方案 [回滚步骤 ↗]
│  └─ ListItem [X]
│     └─ Paragraph                 归档
├─ QuoteBlock
│  └─ Paragraph                    行内文字、链接
└─ LiteralBlock                    源码、示例及其他字面内容
#+end_example

| 控件 | 子内容与职责 |
|-
| ~TaskContentEditor~ | 接收有序正文树和当前文件上下文，分发只读、编辑和导航状态，维护局部更新与当前编辑会话。 |
| ~Paragraph~ | 用共用的 ~InlineContent~ 在一个文字布局中承载文字、格式、换行和链接，由 ArkUI 统一换行和测量。 |
| ~ListBlock~ | 按原顺序组合 ~ListItem~ 。列表样式和标记来自 Core，普通条目和带 checkbox 的条目可混排。 |
| ~ListItem~ | 左侧放项目符号、编号或 checkbox，右侧按顺序放正文子区块。清单项的首段、后续段落、表格和子清单从同一内容列开始。排序手柄与首段对齐，拖动、删除父项时以整个子树为单位。 |
| ~TableBlock~ 、 ~TableRow~ 、 ~TableCell~ | 表格负责列宽、行分隔和滚动，单元格复用 ~InlineContent~ ，链接随单元格文字共同换行。 |
| ~QuoteBlock~ | 绘制引用样式并递归摆放其正文子区块。 |
| ~LiteralBlock~ | 使用原生等宽文字控件呈现源码、示例或暂未支持的 Org 区块。字面内容中的链接写法按原样显示。 |

清单的 checkbox 与段落链接分别接收点击。已完成样式作用于当前项首段，后续说明和子清单保留各自的阅读样式与完成状态。只读和编辑使用同一棵树，关闭写操作后仍可打开链接。列表内使用内容列排布局部高度，整段正文沿用宿主页面的纵向滚动。

对应的 Org 清单中，首段、补充说明、表格和子清单都是第一个条目的直属内容。

* 段落与原位编辑

段落以 Org 的 ~paragraph~ 元素为单位。同一段落可以包含多行连续文本，单次换行保留在段落内。空白行结束当前段落，后续文字建立新段落。列表、表格、引用等独立 Org 元素也会结束当前段落；清单项缩进内可包含多个直属段落以及子列表。

点按直属段落的普通文字打开原位 Org 文本输入。空正文显示“添加正文”，点按后直接输入。编辑已有段落时可输入空白行，保存后按 Org 结构生成多个相邻段落。在任务卡片中点按列表项的首行进入单行输入，回车保存并聚焦下一条同级项。到达列表末项时，回车在该项及其子项之后打开同级新增行。各列表末尾提供新增入口，连续回车可保存并追加。普通条目和 checkbox 条目共用同级排序手柄，拖动父项时预览和保存都携带子项。新增条目沿用锚点的项目符号和 checkbox 类型。

长按直属段落、普通列表或检查清单打开与链接菜单同样式的浮层。菜单增加“在下方添加段落”和“在下方添加列表”，在所选区块之后显示草稿。新增列表预填一个未完成清单项的 Org 标记，用户可直接输入条目或修改列表标记。取消或留空结束草稿时不会写入。可编辑块的拷贝、编辑、删除继续通过同一个菜单。只读仍可长按拷贝。

* 链接的展示、添加与跳转

链接是段落、表格单元格等文本位置中可换行的行内控件。Core 提供显示文字、原始链接引用及语义目标。Harmony 共用链接图标、颜色、菜单和点击分发。点按链接打开目标，点按同段普通文字进入原位编辑，长按链接打开共用链接菜单。链接操作由命中的行内控件处理，checkbox、排序手柄与区块长按分别处理各自的事件。

| 操作位置 | 添加链接的结果 |
|-
| 段落或单元格中的光标、选区 | 在光标处插入链接，或用选中文字作为链接描述。 |
| 空正文、引用容器或清单项的区块末尾 | 在该容器内新增一个含链接的段落。清单项的缩进与子内容归属由 Core 写入。 |
| 列表项之间的插入位置 | 新增同级列表项并在其首段插入链接。新条目类型沿用该列表的插入规则。 |
| 表格 | 选定单元格后插入或编辑链接，保持同行及相邻列的边界。 |

从已有共用链接表单输入目标和描述。清单项的说明段落编辑区提供“添加说明”，打开该项末尾的段落输入。递归文本编辑工具栏提供“链接”，使用当前 Org 原文输入中的选区。直属段落可以直接输入 Org 链接。Core 引用采用 UTF-8 字节范围，输入控件的字符位置先转换，再与原快照核对。新增说明、链接和子清单按 Org 的列表缩进归属于当前项。源码和示例旁的可跳转链接可插入相邻的普通段落。

同文件链接继续支持 CUSTOM_ID、标题、专用目标和命名元素，并沿用 Core 的匹配优先级。文档内复用当前文档的定位器，保存正在编辑的内容后，展开折叠祖先并定位到目标所在章节或导言。在普通任务列表中点按时，按任务所属文件读取目标索引并确认目标，打开文件后由同一定位器跳转。目标失效或草稿保存失败时，停留在原处并给出提示。

* Core 投影和写入方案

~TaskEditContent~ 和 ~DocumentSection~ 通过已有快照传递 ~contentTree~ 。节点的序列化结构如下。

#+begin_example
ContentNode = { id, kind, source, blankLinesBefore, children?, parts?, marker?, checkbox? }

kind = paragraph | list | item | table | row | rule | cell | quote | literal
parts = [{ text, href, isLink, link: TextLink?, styles? }]
checkbox = unchecked | checked | partial
#+end_example

每个区块带当前快照的源引用和前置空白行信息。文字样式使用语义标记，表格分隔和单元格信息由 Core 投影。清单项的勾选状态包含未完成、已完成和部分完成。清单项结构直接包含其直属区块，顺序和归属来自 Org AST。每个链接的 ~TextLink~ 沿用现有值对象，范围相对于所属文本位置，保证同段内多个相同地址的链接可分别识别。界面按语义目标分发链接，Org 原文保留原链接地址和描述。

新控件读取 ~contentTree~ 中的节点和行内数据。过渡期原有 ~blocks~ 、 ~checklist~ 和 HTML 投影继续服务现有消费者。旧缓存缺少 ~contentTree~ 时，先显示已有版式，收到正式快照后切换。空树表示正文为空。树和源引用属于当前快照，Org 文件与同步格式沿用原结构。

修改继续从统一操作组提交。直属区块的原位编辑和下方新增使用已有的 ~replace~ 保存 Org 原文草稿。 ~CONTENT_BLOCK~ 的 ~replaceText~ 保存段落或单元格文字， ~treeLink~ 安全替换或删除现有链接， ~insertLink~ 在当前文本节点定位选区。 ~insertParagraph~ 与 ~insertLinkedParagraph~ 向正文、列表项或引用插入段落，向列表插入同级条目，由 Core 计算 Org 缩进、分隔符和换行。每次操作带原文件版本、任务或章节路径和节点引用，Core 验证节点归属及原始字节后做局部修改。清单的勾选、删除、同级移动和统计通过 ~CHECKLIST~ 提交。同级移动兼容混排中的两种条目，只有带 checkbox 的条目响应勾选。

* 差异更新与验收

界面身份独立于源字节位置。插入前置段落导致源位置变化时，只更新受影响节点的编辑上下文。链接、段落或单元格修改时，仅更新该节点及必要的父级子节点关系。重复兄弟节点按位置、内容和相邻节点匹配。仍有歧义或文件版本已变化时，保留草稿并提示重新读取。拖动父清单项时按整个子树实际高度更新占位，其他条目的编辑和链接命中范围按当前布局刷新。

验收覆盖清单首段、后续说明、表格单元格和子清单里的内部与外部链接，核对只读跳转、从一级任务页跳到所属文件、相同 URL 的局部编辑、嵌套清单移动和 LF／CRLF 保真。通过应用内嵌接口改变当页记录，核对订阅刷新、局部更新、保存失败保留草稿和重开结果。
