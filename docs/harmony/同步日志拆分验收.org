真实设备本轮未连接，因此不能据模拟器结果声称现场已恢复。此前真机错误的具体历史文件仍未取得，已确认的是旧 appStartup／appBackground 与严格请求枚举复用会产生兼容失败。

Cargo workspace 的单元、集成与文档测试全部通过，其中 Core 单元测试 367 项。新增覆盖逐字段 JSON 容错、旧来源、截断 JSON、首行时间、CRLF、重复字段、非法 UTF-8、超限行、零文件成功／失败／取消、文件日志隔离、原文 hash 校验以及损坏历史不阻断新同步。Bridge 另验证空值透传与字段诊断。既有事务失败、回滚、远端基线与 outbox 用例同步通过。

同步历史展示 10 项、任务与日志展示 58 项宿主回归全部通过。正式包与专用测试包均构建成功，未发现编译告警。变更文档通过 Org 内联边界与 org-element 结构检查。

测试仓库先同时保存三份旧整体 JSON：合法 appStartup、包含 appBackground 与错误类型字段的文档、仅含左花括号的截断文档。随后通过实际应用同步和 WebDAV 请求验证。

一次长详情的 UI 布局采集发生工具等待超时，后续通过截图、接口查询及磁盘证据复核；未将超时的空布局文件作为通过证据。

* 读取边界与后续验证

新同步仍枚举一次 history 目录，按文件／目录名判断占用时间；不会打开旧 summary、单文件记录或整体 JSON 作为同步前置条件。日志列表的现代记录只读摘要，旧整体 JSON 只在展示旧历史时解析。本文没有将代码路径检查冒充启动磁盘 I/O 的系统级跟踪实测。

基线和事务恢复材料保持严格读取；本轮新日志写入失败仍依事务边界处理。历史原文缺少必要路径／hash 或 hash 不一致时明确拒绝读取，不回退到其他版本。

真机重新连接后仍需安装保留数据的更新，验证原现场仓库同步、旧日志展示与新日志布局。不得为验收重置仓库、删除基线、历史或 outbox。

* 收尾

专用模拟器的临时 HTTP 服务、端口转发和本机 WebDAV 在本轮验收结束后关闭；其他会话设备不受影响。隔离数据保留在本次专用模拟器，便于后续复核。
