* 范围与实现

TaskEditor 在出现时取得稳定行的 TaskDataSource 并注册 Monitor，退出时取消。DataSet 将确认数据与全部待提交修改合并，统一比较可见字段后按行分发；来源指针始终推进到最新版本，内容相同则不通知编辑器。实现没有新增 Core 查询或修改公开 Core 协议，列表的成员变化、排序和原有草稿保护保持原职责。

* 专项回归

数据集、编辑器、记录操作、阅读管理、通知与角标的 187 项宿主回归全部通过。专项包含：

- 每项来源注册只取得一次当前快照，后续更新不调用 getTask 定位，不通知无关记录。
- 连续修改三个字段，第一项在途时三个乐观值均可见；第一、第二项确认后后续值保持，全部确认只更新文件版本，不增加可见刷新次数。
- 第一项失败只撤销自身，保留第二、第三项；错误定向交付并保留被拒绝的文字草稿。
- 改名保持来源对象和 rowId，删除失败恢复原来源，确认删除后同名新建使用新来源。
- 同文件其他记录没有字段变化时只更新来源中的 fileVersion，不触发可见刷新。
- Monitor 回调中继续编辑，不向后续接收者交付外层旧快照；取消、配置换代及数据集关闭后不接收旧事件。

完整滑动组件旧回归另有 3 项失败及 1 项等待超时；在隔离的未修改 HEAD 中得到相同的四项失败集合，涉及旧的提交等待和保存准备假设。滑动组件产品代码未修改；与本次兼容入口相关的记录订阅启停回归单独通过。此处不将这些既有失败记为通过。

* 独立模拟器实测

最终验收固定使用新建 OrgTaskMonitorQA、HarmonyOS API 24、连接 15561；隔离仓库由模拟器测试包准备。APP 内嵌 HTTP 与界面使用同一个 Workspace，未通过改磁盘文件或重开页面代替实时更新验证。

| 操作 | 实际结果 |
|-
| 展开任务 | 当前卡片显示原标题和备注，其他任务保持收起 |
| HTTP 同批修改三个字段 | 备注、优先级与普通属性提交成功，当前项更新 |
| 输入标题草稿期间 HTTP 再次更新 | 当前项备注和优先级显示新值，未提交的标题草稿保持 |
| 界面结束输入 | API 确认新标题已保存，外部备注和优先级保留，使用最新文件版本，无覆盖或重复提交 |
| HTTP 改名 | 当前展开卡片直接显示新标题，并继续保留备注 |
| 非法 TODO 状态 | Core 返回输入错误，文件版本不变 |
| HTTP 删除当前记录 | 当前卡片移除、编辑会话结束，其他任务保留 |
| HTTP 同名重建 | 新行显示新正文，旧编辑状态未恢复 |
| 安装最终 Debug 包并冷启动 | 查询确认重建记录及正文保持，HTTP 再次改名实时显示 |
| 最终包界面完成任务 | API 确认状态为 DONE，新正文保留，今天列表移除对应行 |

连续排队三字段的各阶段暂停和可见刷新次数由真实 DataSet 队列的宿主回归精确验证；模拟器确认真实平台的 Monitor 接入、草稿、实时更新、移除和重建行为，不将同批 API 写入冒充三次排队提交。

* 验收环境操作记录

数据准备初期误选了已有的 OrgPageDataQA 连接 5555，在其中安装了本次包、创建隔离测试仓库并切换为该测试配置。原仓库文件没有删除或直接修改，但没有操作前的完整配置快照，未猜测覆盖恢复。识别连接后所有实际验收固定到独立的 15561，未继续操作 5555 的应用会话。此环境影响单独保留记录，不计为产品行为或独立模拟器验收结果。

收尾已确认：15561 的临时服务不可连接，本次端口转发已移除，OrgTaskMonitorQA 已停止；未停止其他模拟器。
