#+TITLE: 功能清单

* 目的

本文是 Org Tasks 当前功能范围的唯一清单，用于产品验收、开发排期和变更评审。状态以仓库当前代码为准；设计文档中未接入应用流程的能力必须标为“规划中”，不能视为已交付。

修改用户可见功能、功能入口或交付状态时，必须同步更新本文。领域数据边界以 [[file:core/数据模型.org][数据模型]] 为准，WebDAV 核心能力以 [[file:core/WebDAV 同步能力设计.org][WebDAV 同步能力设计]] 为准，Harmony 配置与保存边界以 [[file:harmony/配置项设计.org][Harmony 配置项设计]] 为准，HTTP 宿主约束以 [[file:http/服务命令行设计.org][HTTP 服务命令行设计]] 为准。

* 状态定义

| 状态 | 含义 |
|-
| 已实现 | 已有用户入口或可执行命令，且主流程已经接入。 |
| 部分接入 | 底层能力已实现，但尚未贯通预期的完整用户流程。 |
| 规划中 | 已有设计或领域模型，但当前没有可用实现。 |
| 不支持 | 当前版本明确不提供的能力。 |

* 应用功能

| ID | 功能 | 用户结果 | 状态 | 主要实现 | 验收要点 |
|-
| APP-001 | 本地目录同步 | 从配置的本地目录读取 ~.org~ 文件并导入日历。 | 已实现 | ~Index.ets~ 、 ~SyncWorkExtension.ets~ 、 ~FileService.ets~ | 目录可读时能解析任务并写入指定日历；目录不存在时不执行日历删除。 |
| APP-002 | WebDAV 连接配置 | 配置 WebDAV 根目录、用户名和密码，并可测试列举远端 org 文件。 | 已实现 | ~Settings.ets~ 、 ~WebDavService.ets~ 、 ~CredentialService.ets~ | 仅接受 HTTPS；配置无效或认证失败时显示失败原因。 |
| APP-003 | WebDAV 缓存同步 | 通过 ~PROPFIND~ 列举并下载远端 ~.org~ 文件至应用私有缓存，成功后刷新缓存文件。 | 已实现 | ~WebDavService.ets~ | 完整列举和下载成功后才移除过期缓存；缓存写入使用临时文件替换。 |
| APP-004 | 手动同步 | 在首页触发从本地目录或 WebDAV 缓存到系统日历的同步，并展示统计结果。 | 已实现 | ~Index.ets~ 、 ~CalendarSync.ets~ | 请求日历读写权限；展示新增、更新、删除和错误数量。 |
| APP-005 | 后台定时同步 | 使用 WorkScheduler 按配置间隔执行同步。 | 已实现 | ~EntryAbility.ets~ 、 ~SyncWorkExtension.ets~ | 默认间隔为 15 分钟；后台失败不应删除既有日历事件。 |
| APP-006 | Org 任务解析 | 解析标题、TODO 状态、优先级、 ~SCHEDULED~ 、 ~DEADLINE~ 、标签、正文和进度。 | 已实现 | ~OrgParser.ets~ | 仅带 TODO 关键字的标题成为任务；解析或读取任一文件失败时取消本轮删除同步。 |
| APP-007 | 日历增量同步 | 以任务 ID 映射系统日历事件，并创建、更新、跳过或删除事件。 | 已实现 | ~CalendarSync.ets~ | 无计划或截止时间的任务不创建事件；任务内容变化更新既有事件；源任务消失时删除对应事件。 |
| APP-008 | 新增任务 | 从应用填写标题、日期、标签和优先级，写入 ~inbox.org~ 。 | 已实现 | ~AddTask.ets~ 、 ~FileService.ets~ | 本地模式追加至配置目录；WebDAV 模式先保存待上传内容。 |
| APP-009 | WebDAV 待上传任务 | 将离线新增任务保存在私有待上传文件，并在下次同步时追加到远端 ~inbox.org~ 。 | 已实现 | ~WebDavService.ets~ | 已存在的远端 inbox 使用 ETag 条件 ~PUT~ ；遇到 ~412~ 保留待上传内容。 |
| APP-010 | 文件浏览 | 浏览本地目录或 WebDAV 缓存中的 org 文件，按状态筛选，并查看文件内容和任务数。 | 已实现 | ~Files.ets~ 、 ~FileDetail.ets~ | WebDAV 模式可显示缓存和待上传标记；非法文件路径不得读取。 |
| APP-011 | 同步设置 | 配置本地目录、inbox 文件、日历名称和后台同步间隔；密码独立安全存储。 | 已实现 | ~Settings.ets~ 、 ~CredentialService.ets~ | 密码不写入 Preferences；保存后后续同步使用新配置。 |

* Rust 核心与接口功能

| ID | 功能 | 用户或调用方结果 | 状态 | 主要实现 | 验收要点 |
|-
| CORE-001 | 本地仓库核心模型与服务 | 调用方可构造 ~OrgWorkspace~ ，并直接由 ~OrgRepo~ 扫描、解析和维护本地 org 文件快照。 | 已实现 | ~core/src/model/~ | 不存在的仓库 ID 被拒绝；扫描会跳过 ~.sync/~ 与符号链接；同步策略只能返回已完成且归属正确的同步记录。 |
| CORE-002 | 保真编辑 | 调用方可替换来源范围或在来源位置插入内容，未修改字节保持原样。 | 已实现 | ~core/src/edit.rs~ | 编辑后重新构造无损解析缓存；过期范围或非法锚点被拒绝。 |
| CORE-003 | 仓库同步记录持久化 | core 将完成记录写入仓库 ~.sync/history/~ ，并在加载时恢复。 | 已实现 | ~core/src/model/service.rs~ | 记录不包含绝对路径、完整 org 内容或凭据；重启后可恢复并作为同步基线。 |
| CORE-004 | Harmony 异步 bridge | ArkTS 经 C++ N-API 在工作线程保存同步结果。 | 已实现 | ~entry/src/main/cpp/napi_init.cpp~ 、 ~NativeSyncRecordService.ets~ | 当前暴露初始化和同步记录保存；不再登记全局作业。 |
| CORE-005 | HTTP 宿主 | 通过 ~org-tasks-httpd~ 提供健康检查及仓库同步记录的追加和查询。 | 已实现 | ~http/src/bin/org-tasks-httpd.rs~ 、 ~http/src/server.rs~ | 默认只监听回环地址；非回环监听必须显式允许并配置 Bearer Token。 |
| CORE-006 | HTTP CSV 仓储 | 以 generation 快照持久化仓库同步记录。 | 已实现 | ~http/src/store.rs~ | 仅 ~current.csv~ 指向的完整快照可见； ~check~ 不修改数据目录。 |
| CORE-007 | WebDAV 验证 CLI | 通过 ~org-tasks sync webdav~ 反复验证一个本地仓库与 WebDAV 端点的同步过程。 | 已实现 | ~core/src/bin/org-tasks/~ 、 ~core/src/webdav/~ | 默认输出阶段和逐文件 action/state、变化与大小； ~--silent~ 无正常输出； ~-v~ 显示脱敏 HTTP 概要与版本信息。 |
| CORE-008 | 同步历史 CLI | 通过 ~history list~ 查询格式化时间、耗时和文件变化摘要，或通过 ~history show <id>~ 查询单条完整记录。 | 已实现 | ~core/src/bin/org-tasks/~ | ~--repo-dir~ 为全局仓库参数；历史查询不要求 WebDAV 参数；不存在的记录 ID 返回错误。 |
| CORE-009 | 本地 Org 文件 CLI | 通过 ~file list~ 查看文件的任务数、大小、MD5 与最后修改时间，或通过 ~file dump <path>~ 检查无损语法树。 | 已实现 | ~core/src/bin/org-tasks/~ 、~core/src/model/service.rs~ | 仅列出仓库内 ~.org~ 文件；任务数统计带 TODO 状态的标题；dump 输出 ~orgize~ 语法树。 |

* 规划中功能

| ID | 功能 | 目标 |
|-
| PLAN-001 | 多同步方式 | 保持 ~SyncPolicy~ 为 core 扩展点，在 WebDAV 外接入其他同步方式。 |
| PLAN-002 | Harmony 仓库写入意图 | 用仓库级写入意图替换 ArkTS 私有待上传文件，并由 WebDAV adapter 的条件写入结果生成同步文件记录。 |
| PLAN-003 | 仓库冲突处理界面 | 消费 ~OrgRepoSyncFileRecord~ 的 ~action/state~ ，提供保留本地、保留远端、另存副本和暂不处理的用户流程。 |

* 当前不支持

| ID | 功能 | 说明 |
|-
| UNSUPPORTED-001 | Git 式行级合并 | 文件同时变更时不执行自动文本合并。 |
| UNSUPPORTED-002 | 非 WebDAV 仓库 | 不支持 Dropbox 等其他同步后端。 |
| UNSUPPORTED-003 | 远端变更推送 | 不接收 WebDAV 服务端主动推送，依赖手动或定时同步。 |
| UNSUPPORTED-004 | Digest 认证 | 当前 WebDAV 使用 Basic 认证。 |
| UNSUPPORTED-005 | 递归远端目录遍历 | 当前列举使用 ~PROPFIND Depth: 1~ ，不提供完整递归同步。 |
| UNSUPPORTED-006 | 通用远端文件编辑 | 除新增任务追加至 ~inbox.org~ 外，不提供编辑、重命名或删除远端 org 文件的界面。 |
