* 状态与边界

~org-tasks-httpd~ 是单仓库的 Web App 宿主。它读取命令行配置，打开 core 管理的本地 ~OrgRepo~ ，创建 ~WebDavSyncPolicy~ 并调用 core 的加载、启动、停止、进度与快照接口。HTTP 只提供页面和访问控制，不实现 org 解析、WebDAV 请求、文件同步决策、文件写回或同步记录生成。

完整本地仓库能力位于 ~core::model~ ，包括文件扫描和解析；完整 WebDAV 同步能力位于 ~core::webdav~ ，包括认证、 ~PROPFIND~ 、 ~GET~ 、条件 ~PUT~ 、冲突识别、下载文件落盘与同步记录生成。core 控制器持有当前 ~OrgRepo~ 、同步记录和运行状态；HTTP 只读取这些 core 数据以渲染页面。进程结束时，HTTP 不额外保存任何状态。

服务只运行一个仓库，内部仓库 ID 由 core 管理，不是命令行参数。多仓库应启动多个服务进程。

* 启动命令

#+begin_src sh
cargo run -p org-tasks-http --bin org-tasks-httpd -- \
  serve \
  --repo-dir ./org \
  --webdav-url https://dav.example.com/org/ \
  --webdav-username alice \
  --webdav-password-file ./secrets/webdav-password
#+end_src

#+begin_src text
org-tasks-httpd serve [OPTIONS]
org-tasks-httpd check --repo-dir <DIR>
#+end_src

| 参数 | 默认值 | 传给 core 的值 | 说明 |
|-
| ~--repo-dir <DIR>~ | 无，必填 | 仓库初始化根目录 | 已存在、可读写的本地 org 仓库。 |
| ~--webdav-url <URL>~ | 无，必填 | ~WebDavSyncPolicy~ 端点 | WebDAV 根目录；只接受 ~https://~ 。 |
| ~--webdav-username <NAME>~ | 无，必填 | ~WebDavSyncPolicy~ 认证配置 | Basic 用户名。 |
| ~--webdav-password-file <FILE>~ | 无，必填 | ~WebDavSyncPolicy~ 认证配置 | 读取一行非空密码到内存；不支持直接传递密码。 |
| ~--listen <IP:PORT>~ | ~127.0.0.1:8787~ | 无 | Web 界面监听地址。 |
| ~--shutdown-timeout-secs <N>~ | ~10~ | 控制器关闭时限 | 等待正在停止的同步的最长秒数。 |
| ~--log-level <LEVEL>~ | ~info~ | 无 | ~error~、~warn~、~info~、~debug~ 或 ~trace~ 。 |
| ~--access-token-file <FILE>~ | 无 | 无 | 非回环 Web 访问的 Bearer Token。 |
| ~--allow-non-loopback~ | ~false~ | 无 | 允许非回环监听；必须同时指定令牌文件。 |

~check~ 仅验证目录可供 core 初始化；它不读取密码、连接 WebDAV、写入文件或监听端口。

* 页面与操作

服务提供浏览器页面，不提供 RESTful API：

| 方法 | 路径 | 行为 |
|-
| ~GET~ | ~/~ | 渲染同步控制台，数据来自 core 当前快照。 |
| ~POST~ | ~/sync/start~ | 调用 core 启动同步，随后重定向到控制台。 |
| ~POST~ | ~/sync/stop~ | 调用 core 请求停止同步，随后重定向到控制台。 |
| ~GET~ | ~/sync/events~ | 以 Server-Sent Events 推送 core 进度、运行状态和完成记录；不是领域 REST 资源。 |
| ~GET~ | ~/healthz~ | 返回服务存活状态。 |

页面显示仓库概览、当前状态、进度、最近一次同步记录及文件 action、state 和脱敏错误。同步运行时按钮状态由 core 快照决定；停止请求只调用 core 取消句柄，不由 HTTP 中断 WebDAV 请求或构造结果。

* 安全与验收

密码和 Token 仅在 HTTP 宿主内存中读取后传入 core 初始化，不写入日志、页面、记录或请求 URL。非回环监听必须同时指定 ~--allow-non-loopback~ 和 ~--access-token-file~ ；除首页和健康检查外，页面操作必须携带 Bearer Token。

- HTTP crate 不定义 WebDAV 传输、同步记录存储、缓存或 outbox。
- core 能接收 policy 并完成启动、进度、停止和记录快照；HTTP 仅调用这些接口。
- 用户可在网页启动同步、观察进度、请求停止，并查看 core 返回的完成结果。
- ~check~ 与页面读取不产生 HTTP 自有持久化数据。
