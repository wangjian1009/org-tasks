#+TITLE: 建立存储库并记下第一条待办
#+DESCRIPTION: 建一个本地存储库，再把第一条任务安排到今天。
#+KEYWORDS: 新手 入门 收件箱 初始化 新建
#+HELP_TOPIC: start
#+LANGUAGE: zh-CN

* 初始化存储库
1. 打开「收件箱」。如果看到「尚未配置仓库」，点「初始化新仓库」。
2. 给存储库起个名字，点「新建仓库」。返回收件箱后，你可以开始记录。
3. 如果提示选择收件箱文件，打开[[file:help-file-entries.org][文件入口说明]]。

已有 Org 文件时，先看[[file:help-existing-files.org][把已有 Org 文件加进来]]。换手机时，可以[[file:help-move-device.org][导入备份配置]]。想在多台设备之间同步，先了解[[file:help-first-sync.org][WebDAV 首次同步]]。

* 记下一条任务
在收件箱点底部的「+」，写下标题并保存。展开任务，选择计划日期「今天」。返回「今天」确认它已出现。要核对任务写入了哪个 Org 文件，可以到「笔记本」打开已绑定的收件箱。

如果主列表里还有「新手引导」项目，可以打开它练习切换 Org 原文和文档。
