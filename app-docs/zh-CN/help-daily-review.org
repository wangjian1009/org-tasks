#+TITLE: 从收件箱整理到今天
#+DESCRIPTION: 每天从收件箱挑出要做的事，再把其他事项安置到合适的列表。
#+KEYWORDS: 每日 整理 计划 等待 随时 某天 日志簿
#+HELP_TOPIC: tasks
#+LANGUAGE: zh-CN

* 先收集，再安排
想到一件事就记到收件箱。整理时决定下一步。今天做的事项可设置计划日期「今天」。后面某天开始的事项设置未来日期，并在「计划」查看。

* 把注意力留给现在
| 入口 | 什么时候用 |
|-
| 今天 | 查看今天、过期或已进入截止预警期的事项 |
| 计划 | 查看明天起的安排 |
| 等待 | 跟踪需要别人先行动的事项 |
| 随时 | 找没有计划或截止日期的待办 |
| 某天 | 收好以后再考虑的事项 |
| 备忘 | 保存无需完成的参考内容 |
| 日志簿 | 回看已完成或取消的任务 |

想理解计划时间和截止日期的区别，见[[file:help-dates.org][设置计划、截止和提醒]]。
