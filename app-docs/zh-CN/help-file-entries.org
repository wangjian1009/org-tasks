#+TITLE: 设置收件箱、某天和备忘
#+DESCRIPTION: 给每个入口选择一个 Org 文件，方便记录和找回内容。
#+KEYWORDS: 收件箱 某天 备忘 文件入口 绑定 未设置
#+HELP_TOPIC: projects
#+LANGUAGE: zh-CN

* 选择入口文件
1. 打开「设置 → 文件入口」，或点[[orgtasks://page/file-entries][前往文件入口设置]]。
2. 选择「收件箱」「某天」或「备忘」，根据存储库和路径选中文件，再点「确认」。
3. 打开对应入口，确认能看到目标文件中的内容。

快速捕捉写入收件箱。通过任务菜单移到「某天」或「备忘」的内容，可以在相应页面找到。

* 找不到文件时
还没配置存储库时，先[[file:help-first-task.org][建立存储库]]。已经配置时，到「笔记本」检查原文件是否仍在。文件更名或移动后，回到「文件入口」重新选择。
