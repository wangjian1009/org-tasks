#+TITLE: 自定义任务状态与流程
#+DESCRIPTION: 在 Org 文件声明自己的状态，再设定它在应用里属于哪一类。
#+KEYWORDS: 自定义任务 TODO 状态分类 HOLD 等待
#+HELP_TOPIC: tasks
#+LANGUAGE: zh-CN

* 在文件里声明状态
用 Org 编辑器编辑文件，在现有 TODO 声明中加上 ~HOLD~ 。例如下面的流程包含待办、暂缓和完成三个状态。

#+begin_example
#+TODO: TODO HOLD | DONE
#+end_example

在任务标题使用 ~HOLD~ ，保存文件后重新查看任务。没有配置分类时，应用按竖线两侧的待办和完成规则识别这个状态。

* 归到等待列表
在「设置 → 任务状态分类」找到「等待」，点加号添加 ~HOLD~ 。返回「等待」，确认符合条件的任务已出现。如果找不到，先核对文件声明，再检查手机里的分类。
