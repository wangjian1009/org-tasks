# core 模块规范

本文件适用于 `core/` 及其子目录，项目级架构、文档与提交规范遵循根目录 `AGENTS.md`。

## 对外接口变更必须确认

- 修改 Core 模块对外接口前，必须先向用户说明具体接口方案及影响，获得明确确认后才能修改实现。
- 对外接口包括供 Core 以外的模块或宿主使用的 Workspace 入口、公开类型，以及查询、修改和事件的请求／响应结构。新增或删除接口、修改参数或返回值、改变序列化字段和对外语义，都需要确认。
- 用户已经明确指示的具体接口变更视为已确认，无需重复询问；该确认不扩展到其他尚未说明的接口变更。
- 尚未确认时可以先调查现有实现、整理设计与兼容性影响，但不能自行变更对外接口。
- 确认后按根目录规范同步实现、调用方、接口文档和必要的验证。
